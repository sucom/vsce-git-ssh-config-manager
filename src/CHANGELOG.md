## 🎉 v1.0.0 — Initial Release (2026-04-26)

- ✨ **Sidebar View**: Interactive tree view for SSH configurations.
- 🧙 **Key Generation Wizard**: Guided setup for Ed25519, RSA, and ECDSA keys.
- 📝 **Auto-Config**: Automatically appends new hosts to `~/.ssh/config`.
- 📋 **Copy Public Key**: Quick action to copy `.pub` content to clipboard.
- 📂 **Jump to Source**: Open config file directly at the host's line.
- 🔄 **Live Watcher**: Auto-refresh list when config file is modified externally.
- 🎨 **Syntax Highlighting**: Built-in highlighting for SSH config files.
